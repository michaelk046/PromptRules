# PromptRules

PromptRules is a desktop application for managing AI animation projects. It organizes projects, episodes, scenes, characters, assets, and reusable prompt rules into a structured workflow that compiles consistent prompts for AI image and video generation.

## Features

| Feature         | Description                             |
| --------------- | --------------------------------------- |
| 📁 Projects     | Organize multiple AI animation projects |
| 🎬 Episodes     | Manage episodes and scenes              |
| 👥 Characters   | Maintain character consistency          |
| 📦 Assets       | Track reusable objects                  |
| 📜 Prompt Rules | Build reusable prompt components        |
| ⚙️ Compiler     | Generate model-specific prompts         |
